# Integration Guide

## Roles
- **Member 1 (Backend)**: FastAPI, Database, Core Business Logic, API Contracts.
- **Member 2 (Collector App)**: Flutter, SQLite, Offline UX.
- **Member 3 (Web)**: Next.js, Aggregator, Recycler, Brand/PRO, Admin.

## Principles
- **Backend as Source of Truth**: Business rules, state validation, authorization.
- **Shared Contracts**: API request/response structures, entity IDs, lifecycle states, event types, roles, permissions.
- **Offline Sync (Member 2 ↔ Member 1)**:
    - Queue: PENDING → SYNCING → SYNCED/FAILED.
    - Idempotency: `client_transaction_id` must be generated by collector app for every new entity.
    - Syncing: Retry until server acknowledgement.
    - Photos: Syncing mechanism (TBD).
    - Location: GPS coordinates must accompany collection events.
- **Errors**: Handle server-side validation errors appropriately on the client.
- **Collaboration**: Branches: `backend-dev`, `collector-dev`, `web-dev`. Merges to main require PR review.
- **Breaking Changes**: Update contracts first, then consumers, then tests.
